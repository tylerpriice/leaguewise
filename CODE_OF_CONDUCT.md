# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Its full text is at that address and applies here as written.

It covers every space this project runs: this repository's issues, pull requests, and discussions, and any email sent to the project.

## In short

- Be respectful. Disagree about the work, not about the person.
- Assume good faith, and say so plainly when something is wrong.
- No harassment, no insults, no personal attacks, and no publishing anyone's private information.
- This is a project about fantasy sports. Trash talk belongs in your league, not here.

## Reporting

If someone's behaviour here breaks this code, write to **admin@leaguewise.net**. Say what happened and where, with a link if there is one.

Reports are read by the project's maintainer and kept private. Nobody is named publicly for making a report.

## What happens next

The maintainer decides what a report calls for, following the Covenant's enforcement guidelines: a correction, a warning, a temporary ban, or a permanent one. A comment, issue, or pull request that breaks this code may be edited or removed.
