# Roadmap

Where Leaguewise is going, in four lists. No dates. A direction, not a promise: items move when
the work behind them is measured, and the Never list is the one part that does not move.

## Now

The current release. What it holds is in `CHANGELOG.md`.

## Next

- **Microsoft Edge.** The same package the Chrome Web Store serves, listed on Edge Add-ons.
- **Firefox for Android.** The dashboard at phone width, as one scrolling column.
- **A live demo.** The dashboard on a sample league, open to anyone, no install and no account.

## Later

- **ESPN Fantasy Basketball.** The engines carry over; every stat id is validated on real lines
  before a sport ships, so this waits on that work.
- **Safari.** The one platform where a paid build would cover a real cost, Apple's developer fee.
  Safari 18 and later only.
- **Other hosts.** Sleeper and Yahoo read-only, as adapters, after the ESPN work above.

## Never

- A server that holds your league data, or an account to use the extension.
- Telemetry, analytics, or advertising.
- Lineup automation, or any write to ESPN. Leaguewise reads.
- A paid lock on analysis that has already shipped free.

Leaguewise is a free, open-source extension. A separate paid product may exist one day beside
it. The extension stays free and does not shrink.

## How to move this

Open an Idea in Discussions, or add to one that exists. The ones with the most people behind
them are the ones that get measured first.
